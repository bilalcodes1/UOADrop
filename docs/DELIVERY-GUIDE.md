# دليل تسليم UOADrop للمكاتب والمكتبات

## الملفات المطلوبة

| الملف | الموقع | الاستخدام |
|-------|--------|-----------|
| `UOADrop Setup 0.1.5.exe` | `apps/desktop/release/` | تثبيت على Windows |
| `UOADrop 0.1.5.exe` | `apps/desktop/release/` | نسخة محمولة Windows بدون تثبيت |
| `UOADrop-0.1.5-arm64.dmg` | `apps/desktop/release/` | تثبيت على Mac Apple Silicon |
| `UOADrop-0.1.5.dmg` | `apps/desktop/release/` | تثبيت على Mac Intel |

## خطوات التثبيت على جهاز صاحب المكتب (Windows)

1. **انسخ** `UOADrop Setup 0.1.5.exe` على فلاشة USB
2. **شغّل** الملف على جهاز صاحب المكتب
3. إذا طلع تحذير Windows SmartScreen: اضغط **More info** ← **Run anyway**
4. اختر مسار التثبيت (الافتراضي مقبول) ← **Install**
5. **شغّل التطبيق** من قائمة Start أو سطح المكتب

## أول تشغيل

- **PIN الدخول**: `12345`
- التطبيق يبدأ بشاشة القفل — ادخل الـ PIN
- الداشبورد يظهر فارغ (لا توجد طلبات بعد)
- من الإعدادات، أدخل **كود التفعيل** الخاص بالمكتب حتى يرتبط التطبيق بالمكتب الصحيح.
- بعد التفعيل، يظهر اسم المكتب ورابط الرفع الأونلاين الخاص به.

## اختبار الرفع المحلي (من داخل المكتب)

1. من جهاز صاحب المكتب — افتح المتصفح وادخل `http://localhost:3737`
2. يظهر **ملصق الحائط** بـ QR code
3. من **موبايل أي طالب** على نفس شبكة Wi-Fi:
   - امسح الـ QR أو ادخل العنوان المعروض (مثل `http://192.168.1.X:3737`)
   - ارفع ملف PDF أو صورة
   - اختر إعدادات الطباعة
   - اضغط **إرسال**
4. **بجهاز صاحب المكتب**: يظهر إشعار + الطلب يظهر بالداشبورد
5. اضغط **طباعة** ← يفتح الملف بالتطبيق الافتراضي

## اختبار الرفع الأونلاين (من خارج المكتبة)

1. من أي جهاز ادخل: **https://uoadrop.vercel.app**
2. ارفع ملف + اكتب الاسم + البريد
3. بجهاز صاحب المكتب: الطلب يظهر بعد ثوانٍ بعلامة 🌐
4. إذا دخل الطالب من الرابط العام، يختار المكتب من القائمة.
5. إذا دخل من باركود المكتب، يتم تحديد المكتب تلقائياً.

## اختبار الإشعارات

- **Telegram**: بعد رفع طلب أونلاين — يوصل تنبيه على البوت
- **Email**: يوصل إيميل عند تغيير حالة الطلب

## استكشاف المشاكل

| المشكلة | الحل |
|---------|------|
| التطبيق ما يفتح | Right-click ← Run as Administrator |
| SmartScreen يمنع | More info ← Run anyway |
| الطلبات الأونلاين ما تظهر | تأكد من اتصال الإنترنت |
| الموبايل ما يقدر يوصل | تأكد إن الموبايل وجهاز صاحب المكتب على نفس شبكة Wi-Fi |
| الأونلاين ما يرتبط بالمكتب | تأكد أن كود التفعيل مولّد من لوحة الأدمن وأن المكتب مفعّل |
| الطابعة ما تطبع | تأكد إن الطابعة معرّفة كـ Default Printer بالنظام |
