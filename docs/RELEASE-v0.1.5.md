# UOADrop v0.1.5 — إصدار التسليم النهائي الأولي

## الخلاصة

هذا الإصدار يحوّل UOADrop من تجربة محصورة بمكتبة واحدة إلى منظومة تعمل مع كل مكاتب الطباعة والمكتبات المسجلة.

## أهم التغييرات

- دعم مكاتب/مكتبات متعددة، وكل جهة لها كود تفعيل ورابط رفع وباركود خاص.
- صفحة الرفع العامة تعرض اختيار المكتب عند عدم وجود رابط خاص.
- رابط الباركود يحدد المكتب تلقائياً عبر `?library=<slug>`.
- تطبيق الديسكتوب يعرض اسم المكتب المرتبط ورابط الرفع الأونلاين الصحيح.
- إمكانية إعادة التفعيل أو تغيير المكتب من إعدادات الديسكتوب.
- إرسال إشعارات Email وTelegram عبر Desktop Gateway بدل أي مفاتيح حساسة داخل الديسكتوب.
- لوحة الأدمن تدعم إنشاء المكتبات، توليد أكواد التفعيل، نسخ الأكواد، تعطيل/تفعيل، وحذف المكتبات عند الحاجة.
- تحديث صفحة تحميل التطبيق لتوضح أن النظام صار لكل مكاتب الطباعة والمكتبات المسجلة.
- تحديث الوثائق ودليل التسليم وChecklist الإصدار.

## ملفات التحميل

- `UOADrop Setup 0.1.5.exe` — Windows Installer x64.
- `UOADrop 0.1.5.exe` — Windows Portable x64.
- `UOADrop-0.1.5-arm64.dmg` — macOS Apple Silicon.
- `UOADrop-0.1.5.dmg` — macOS Intel.
- `UOADrop-0.1.5-arm64-mac.zip` — macOS Apple Silicon ZIP.
- `UOADrop-0.1.5-mac.zip` — macOS Intel ZIP.
- `SHA256SUMS.txt` — بصمات التحقق للملفات.

## متطلبات التشغيل

- إنشاء المكتب/المكتبة من لوحة الأدمن `/admin`.
- توليد كود تفعيل للمكتب المطلوب.
- إدخال كود التفعيل من إعدادات تطبيق الديسكتوب.
- إبقاء أسرار Supabase وTelegram وSMTP والتشفير داخل Vercel فقط، وليس داخل تطبيق الديسكتوب.

## ملاحظات مهمة

- الإصدارات الحالية غير موقعة رقمياً؛ قد يظهر تحذير SmartScreen على Windows أو تحذير فتح التطبيق على macOS.
- Code signing وAuto-update تبقى خطوات تحسين لاحقة.
- السعر النهائي يبقى يدوياً ومن الداشبورد فقط.
